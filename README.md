## How to Install

1. Open Dalamud settings in-game: `/xlsettings`
2. Navigate to **Experimental** tab
3. Scroll down to **Custom Plugin Repositories** and add:
   ```text
   https://raw.githubusercontent.com/1Stalk/DalamudPlugins/main/pluginmaster.json
   ```
4. Click **+** (Add) and **Save and Close**
5. Open the plugin installer (`/xlplugins`) and install the plugin you want!
